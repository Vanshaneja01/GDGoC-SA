Core Mission

The Three Pillars of GDG on Campus

Empowering student developers of all backgrounds to grow their technical knowledge, build meaningful projects, and solve real community challenges.

1. Connect

Meet students passionate about developer technologies on your campus and globally. Build lifelong professional relationships, share ideas, and find teammates for international hackathons.

2. Learn

Gain practical, industry-aligned skills through interactive workshops, code labs, Google Cloud Study Jams, and machine learning sprints led by experienced mentors and ambassadors.

3. Grow

Apply your skills to build real-world products for local organizations and enter the global Google Solution Challenge addressing the United Nations 17 Sustainable Development Goals.

Learning Pathways

Google Developer Technology Tracks

Hands-on curriculum tracks organized by student ambassadors and supervised by faculty mentors.

Track 01

🤖 AI & Machine Learning

Explore generative AI with Google Gemini, prompt engineering, TensorFlow, Keras, Vertex AI pipelines, and computer vision models.

Track 02

☁️ Cloud & DevOps

Master Google Cloud Platform (GCP), Docker containers, Kubernetes orchestration, serverless microservices, and CI/CD pipelines.

Track 03

📱 Flutter & Android

Build cross-platform mobile apps using Flutter and Dart, alongside modern native Android development with Kotlin and Jetpack Compose.

Track 04

🌐 Modern Web Technologies

Develop responsive, accessible web applications using Angular, Progressive Web Apps (PWAs), WebAssembly, and modern browser APIs.
